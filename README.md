# Triple Espresso

## Descripción

Triple Espresso es una página web para una cafetería ficticia ubicada en Ciudad Triple Peaks. El sitio presenta información general de la cafetería, horarios de atención, una sección para reservar una mesa y un pie de página con redes sociales.

## Funcionalidades

- Encabezado con navegación interna.
- Sección principal con imagen e información de la cafetería.
- Formulario para reservar una mesa.
- Validación básica de campos obligatorios con HTML.
- Pie de página con enlaces a redes sociales.
- Efectos hover en enlaces y botón de reserva.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Formularios HTML
- Metodología BEM
- Git y GitHub
